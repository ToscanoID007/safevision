El robot sólo usa redes de 2.4 GHz. Las redes de 5 GHz aparecen en gris y no se pueden elegir. Si tu módem emite las dos bandas con nombres distintos, elige la de 2.4 GHz.

Tampoco funcionan las redes que piden iniciar sesión en una página web ni las que piden usuario además de contraseña (redes institucionales tipo empresa). Si el robot no encuentra ninguna red conocida al encender, crea la suya: SafeVision-Robot, siempre en 10.42.0.1.
